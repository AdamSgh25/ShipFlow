# ShipFlow — Multi-Company Shipping Management Platform (Frontend)

Built with Vue 3 (Composition API), Vite, Vue Router, Pinia, Axios, Tailwind CSS, and Lucide Vue Next.

## Quick Start

```bash
npm install
npm run dev
```

Configure `VITE_API_BASE_URL` in `.env` to point to your backend API server (default: `http://localhost:8080`).
